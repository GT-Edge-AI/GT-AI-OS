# Tenant Admin

Welcome to the Tenant Admin section. These guides are for Tenant Admins who manage users, monitor usage, and configure organization-wide settings.

## Admin Capabilities

As a Tenant Admin, you have access to:

| Feature | Description |
|---------|-------------|
| [User Management](tenant-admin/users) | Add, edit, and manage users |
| [Observability](tenant-admin/observability) | Monitor usage and conversations |

## Getting Started

### Accessing Admin Features

Tenant Admin features are visible in the sidebar:
- **Users**: Manage organization members (Tenant Admin only)
- **Observability**: Monitor platform usage (available to all users with role-based filtering)

The Users menu only appears for Tenant Admins.

### Understanding Your Role

As a **Tenant Admin**, you can:
- Manage all users in your organization
- Access conversation monitoring for all users
- View usage analytics
- See ALL resources regardless of visibility settings
- Set resource visibility to **Organization** (making resources available to all users)

## Best Practices

### Regular Maintenance

- Review user accounts quarterly
- Disable inactive users
- Update team memberships

### Security

- Review access logs regularly
- Promptly disable departing employees
- Report suspicious activity to your Super Admin

### Communication

- Document organizational policies
- Communicate changes to users
- Provide training for new features
- Gather feedback from users
