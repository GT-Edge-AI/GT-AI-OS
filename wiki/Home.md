# Getting Started with GT AI OS

Welcome to GT AI OS, your enterprise AI platform. This guide will help you get oriented and start using the platform effectively.

## Interface Overview

The GT AI OS interface consists of several key areas:

- **Sidebar** (left): Navigate between different sections, view conversation history, and access your profile
- **Main Content Area** (center): Where you interact with agents, manage datasets, and perform tasks
- **Chat Interface**: Your primary way of interacting with AI agents

## Quick Start Checklist

1. **Browse Available Agents**: Visit the Agents page and click on any agent card to begin a conversation
2. **Continue Conversations**: The Chat page opens when you select an agent. Use the sidebar conversation history to continue previous chats or select a new agent to start fresh.
3. **Check Your Datasets**: If you have documents to work with, visit the Datasets page to see what's available
4. **Join Your Teams**: Visit the Teams page to see team invitations and join collaborative workspaces

## Key Concepts

### Agents

Agents are customized AIs within GT AI OS. Each agent is configured with:
- A personality that shapes how it communicates (formal, friendly, technical, etc.)
- Access to your uploaded documents (Datasets) for informed answers
- A system prompt that defines its expertise and behavior

Think of them as different experts you can talk to - one might be great at technical support while another excels at research.

### Datasets

Datasets are collections of documents that provide context to agents. When you attach a dataset to an agent or a conversation, that agent can search the documents for relevant information to include in responses.

### Teams

Teams allow you to collaborate with colleagues. Team members can share:
- Agents created for the team
- Datasets relevant to team work
- Conversation insights (if enabled)

## Navigation

Use the sidebar to access different areas:

| Section | What You Can Do |
|---------|-----------------|
| Conversation History | View and continue previous conversations |
| Agents | Find existing agents or create new ones. The page has two views: **Favorite Agents** (landing page) and **Agent Configuration** - switch between them using the button in the top right. |
| Datasets | Upload documents (PDF, Word, etc.) for agents to reference |
| Teams | Collaborate with colleagues by sharing agents and datasets |
| Observability | Review your conversations, usage patterns, and storage |
| Users | *(Tenant Admin only)* Add or manage organization members |

## Getting Help

Click the **Instructions** button in the sidebar to access documentation. This opens a menu with:
- **GT AI OS Instructions**: Opens this interactive documentation
- **External Docs**: Links to additional resources (if configured by your Tenant Admin)

For other support:
- Use the **Contact Support** option for help from your organization
- Reach out to your Tenant Admin for organization-specific questions
- Look for a **Teams** badge indicator - if you see a number, you have pending team invitations
