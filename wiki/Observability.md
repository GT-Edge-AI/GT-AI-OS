# Observability

The Observability page lets you review your activity on the platform, including conversation history, usage patterns, and storage consumption.

## Accessing Observability

Click **Observability** in the sidebar to open the dashboard. You'll see three tabs:

| Tab | What It Shows |
|-----|---------------|
| Usage Overview | Your usage metrics and trends over time |
| Conversations | Browse and search your conversation history |
| Storage | Your dataset and conversation storage usage |

## Usage Overview

The Usage Overview tab shows your personal activity metrics.

### Metrics

At the top of the page, you'll see summary cards showing:
- **Total Conversations**: Number of conversations you've had
- **Total Messages**: Messages exchanged across all conversations
- **Total Tokens**: Token usage across all conversations

### Time Range

Select a time range to view your activity:
- Preset options: 1, 7, 30, 90, or 365 days
- Custom date range for specific periods

### Charts

View your activity over time with interactive charts:
- **Conversations over time**: When you had conversations
- **Messages over time**: Message volume trends
- **Tokens over time**: Token consumption patterns

Switch between chart types using the dropdown menu.

### Breakdowns

See how your usage breaks down:
- **By Agent**: Which agents you used most
- **By Model**: Which AI models were used

### Exporting Charts

Click the export button on any chart to download it as a PNG image.

## Conversations

The Conversations tab lets you browse and search your conversation history.

### Browsing Conversations

The conversation list shows:
- Conversation title
- Agent used
- Number of messages
- Token count
- Date created and last updated

Click any conversation to expand and view the full message history.

### Searching

Use the search box to find conversations by:
- Keywords in the conversation
- Conversation title

### Filtering

Narrow down your conversations using filters:
- **Date range**: Specific time periods
- **Agent**: Conversations with a specific agent
- **Sort by**: Created date, updated date, or relevance

### Viewing Conversation Details

When you expand a conversation, you can see:
- Full message history
- Who sent each message (you or the agent)
- Timestamps for each message
- Token counts per message
- Which AI model was used

### Exporting Conversations

Export your conversations for offline review or record-keeping:

1. Click the **Export** button
2. Choose your export scope:
   - Single conversation
   - All conversations matching your filters
   - All your conversations
3. Select format:
   - **CSV**: Spreadsheet-compatible format
   - **JSON**: Structured data format
4. Optionally include full message content
5. Click **Export**

## Storage

The Storage tab shows how much storage your data uses.

### Overview

See your total storage usage:
- Total storage consumed (MB)
- Number of documents
- Number of datasets
- Average document size

### Storage Breakdown

View storage distribution by:

**Dataset Storage**
- Storage used by each of your datasets
- Expand to see individual files
- File details: name, size, type, upload date

**Conversation Storage**
- Storage used by conversations
- Includes message data and any attached files

### Charts

Visual breakdowns showing:
- Storage distribution across datasets
- File type breakdown (PDF, DOCX, TXT, etc.)

## Tips

- **Check regularly**: Monitor your usage to understand your patterns
- **Export important conversations**: Keep records of valuable interactions
- **Review storage**: Clean up unused datasets to manage storage
